# Blockchain Voting System

A Menu-Driven Console App For Voting-Management-System

## Usage

Run the program:
```bash
python voting_system.py
```

## Input value  :
1. Add Candidate
2. Add Voter
3. Cast Vote
4. Print Blockchain
5. Validate Chain
6. Exit
